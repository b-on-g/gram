# $bog_gram_avatar

Кружок с узором по лорду. Цвет узора задаётся `tint`, номером из палитры `$bog_gram_tone.tints`. Узор рисуется обводкой `currentColor`, поэтому цвет красит сами точки, а не подложку. Размер задаёт место использования.

Базовый узор `$mol_avatar` кладёт точки с шагом 2.7 при толщине 3.5: они перекрываются, и у длинных идентификаторов картинка сливается в пятно. Здесь шаг крупнее толщины: точек меньше, зато узор читается.

Сетка прямоугольная, а рамка круглая, поэтому угловые точки срезались краем. Узор вписан в окружность радиуса `center - 2.5` (половина толщины точки и зазор): точка, которая не помещается целиком, не рисуется вовсе.
