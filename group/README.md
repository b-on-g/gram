# $bog_gram_group

Страница новой группы. Устроена как «новый диалог»: сверху название и уже выбранные, снизу, кого можно позвать.

- Позвать можно собеседников своих переписок и людей из реестров, см. `contacts` в `$bog_gram_roster`. Ключи первых уже лежат в их лендах, и такой список работает без сети. Один человек одна строка, подписью берётся переписка, она ближе.
- Черновик группы (название, выбранные, потерянные ключи, набранный ID) живёт в `$bog_gram_crew`. Список ненайденных ключей относится к прежнему составу, поэтому любая правка выбора его снимает.
- Идентификатор можно набрать руками. Заведомая опечатка отсеивается сразу: группа с несуществующим участником его бы не дождалась.
- Кого не удалось добавить, страница называет по именам тревожной строкой, а кнопка меняется на «Создать без них».
