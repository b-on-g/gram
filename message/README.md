# $bog_gram_message

Сообщение. Порядок задаётся полем `Moment` в самих данных, а не порядком доставки.

- `Edited`: момент последней правки. Нет значения, значит сообщение не правилось.
- `Deleted`: момент удаления. Удаление это флаг, сама запись из списка не выкидывается.
- `Image`: картинка лежит в своём ленде. Переписка синкается налегке, а тяжёлый кадр приезжает отдельно и только когда его показывают.
- `Image_width`, `Image_height`: размеры кадра в пикселях. Место под него в ленте занимается заранее, и приехавшая картинка ничего под собой не сдвигает.
- `Voice`: голосовое тоже лежит в своём ленде.
- `Voice_span`: длительность записи в секундах. Едет вместе с сообщением, до самого звука, и длину пузырь показывает сразу.
- `Reply`: ссылка на сообщение, на которое это ответ.
