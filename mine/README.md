# $bog_gram_mine

Своего хранилища у Gram больше нет: юниты и болы Гипер Базы лежат в общей базе
домена `$giper_baza_mine` — той же, что у Music. Один аккаунт на все приложения
означает и одно локальное хранилище: иначе одни и те же ленды качались бы дважды
и расходились при сбросе.

Модуль остался ради разового переноса. Пока в браузере жива старая база
`bog_gram_mine`, при старте она копируется в общую и удаляется — иначе после
смены аккаунта пришлось бы заново тянуть всю переписку с мастеров. Перенос
одноразовый: если в общей базе уже что-то есть, старая просто остаётся лежать.

Ключ аккаунта — тоже общий, см. `$bog_gram_auth`.
