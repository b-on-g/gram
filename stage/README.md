# $bog_gram_stage

Холст между камерой и кодировщиком кружка, чтобы камеру можно было сменить посреди записи.

- `MediaRecorder` не переживает замену видеодорожки в своём потоке: Chrome роняет запись, Safari пишет мусор. Поэтому кодировщик пишет с холста (`captureStream`), а на холст каждый кадр рисуется текущая камера. Смена камеры меняет только источник холста (`source`), запись идёт дальше.
- Пока новая камера открывается, на холсте последний кадр старой: на телефоне две камеры сразу не открыть, старую приходится гасить раньше.
- Кадр режется в квадрат по середине (`crop`) и рисуется 480×480.
- Нет `captureStream` (`able()` ложно) — кружок пишется прямо с камеры, как раньше, и сменить её можно только до записи.
