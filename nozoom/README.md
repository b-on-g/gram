# $bog_gram_nozoom

Safari увеличивает всю страницу, когда фокус уходит в поле ввода, и масштаб обратно не возвращает: приходится разводить страницу пальцами, чтобы дотянуться до кнопки отправки. Шрифта в 16 px хватает не всегда: в приложении на домашнем экране зум случается и при нём.

Поэтому на время ввода масштабирование запрещается (`maximum-scale=1` во viewport), а как только фокус ушёл из поля — возвращается. Пинч-зум доступен всегда, кроме промежутка, пока человек печатает.

Возврат откладывается на 300 мс: при переходе между полями фокус успевает моргнуть, и без паузы масштаб дёргался бы туда-сюда.
