# $bog_gram_row

Строка списка: кружок, заголовок со временем, подпись с бейджем, справа кнопки. Одна и та же для диалогов, избранного, архива, запросов, людей из реестров, выбора в группу, участников, заявок и реестров.

```tree
<= Dialog_row* $bog_gram_row
	size \large
	click? <=> dialog_select*?
	current <= dialog_current_is*
	avatar_id <= dialog_avatar_id*
	tint <= dialog_tint*
	title <= dialog_title*
	time <= dialog_time*
	note <= dialog_preview*
	badge <= unread_label*
	tools /
		<= Dialog_delete* $mol_button_minor
```

- `size`: `large` для списка диалогов (кружок 3rem, жирный заголовок), `small` по умолчанию для людей, `tiny` для плашки выбранного в группу.
- `Icon`: значок вместо узора лорда, как у избранного и архива. `faced false` убирает кружок вовсе, как у реестра.
- `marks`: значки справа, клик по которым остаётся кликом по строке.
- `tools`: кнопки справа. Они лежат внутри кликабельной строки, поэтому `Tools` гасит всплытие клика: иначе корзина заодно открывала бы удаляемый диалог. Обработчикам кнопок об этом думать не нужно.
- `enabled false`: строка без своего клика, как у участника группы. Кнопки внутри неё остаются нажимаемыми: `pointer-events` строке возвращён.
- `current`: выбранная строка заливается цветом управления, текст в ней белый. Время и подпись приглушаются прозрачностью, а не цветом, чтобы на выбранной строке они тоже стали белыми.

Пустые время, подпись и бейдж из строки убираются. У колонки с текстом нулевой `min-width`: без него многоточие не срабатывает, и колонка распирается содержимым.

На телефоне строки плотнее, а кнопкам добавлен запас до 2.75rem: 44 точки, минимум под палец по гайдлайну Apple. Соседние кнопки стоят вплотную, и без запаса палец накрывал бы сразу две.

Размеры и кнопки описаны в `row.view.css` атрибутами строки. Модуль строки грузится после модулей, которые им пользуются, и правило потребителя той же специфичности, что у строки, проигрывает ему. Отличия от умолчаний поэтому задаются свойствами строки, а не стилями снаружи.
