# $bog_gram_dialog

Шаренный между участниками ленд диалога: участники и ссылки на сессии-бакеты. Группа это тот же ленд, у неё больше двух участников или есть название.

- `Peers`: все участники, включая создателя.
- `Sessions`: все бакеты переписки. Бакетов больше одного, когда кого-то убрали из группы или добавили без истории.
- `Owner`: кто завёл переписку. Королём ленда числится служебный ключ, выданный при захвате, поэтому по самому ленду создателя не узнать, и он пишется прямо.
- `Session_last`: бакет, в который идёт запись. Порядок в `Sessions` задаётся слиянием, а не добавлением, поэтому «последний» там не обязательно свежий.
- `Created`: момент создания, по нему пустой диалог сортируется в списке.
- `Title`: название группы. У переписки вдвоём его нет: там заголовок это личная подпись собеседника, и лежит она в приватном ленде.
- `Admins`: кто может звать и убирать людей. Создатель админом остаётся всегда, даже не числясь тут.
