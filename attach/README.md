# $bog_gram_attach

Кнопка выбора файла, которая сбрасывает своё поле после каждого выбора. Поле выбора файла помнит прошлый выбор и о повторе того же файла не сообщает: без сброса одну картинку нельзя было бы отправить дважды.

Сброс делает само поле `$bog_gram_attach_native` в своём обработчике выбора, снаружи к его разметке никто не тянется.
