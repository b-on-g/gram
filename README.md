# Gram

Простой мессенджер на [$mol](https://mol.hyoo.ru/) и [Гипер Базе](https://baza.giper.dev/): local-first, p2p-синхронизация через мастер-узлы, шифрованные диалоги. Аккаунт — пара ключей в браузере, никакой регистрации.

**[Открыть](https://b-on-g.github.io/gram/)** · **[Исходники](https://github.com/b-on-g/gram)**

## Как это устроено

Архитектура по разбору Карловского:

- **user** — публичный профиль в home-ленде: имя + ссылки на служебные ленды
- **dialogs** — приватный шифрованный список диалогов и известных владельцу реестров
- **dialog** — шаренный между участниками ленд: участники + сессии
- **session** — отдельный ленд-бакет с сообщениями и позициями прочтения
- **message** — порядок задаётся полем Moment в данных, а не порядком доставки
- **inbox** — лобби-ленд для доставки инвайтов и заявок в группу (писать могут все, с PoW)
- **users** — реестр для обнаружения собеседников: название задаёт создатель, вступают по кнопке
- **monitor** — публичный список лендов для будущего пуш-сервиса

Мастер по умолчанию — `baza.87.120.36.150.ip.giper.dev`, переопределяется параметром `#!baza=<url>`.

Ссылки: `#!invite=<лорд>` открывает личный диалог сразу, `#!join=<ленд группы>` шлёт заявку — ключ от шифрованной переписки выдаёт админ поимённо, мгновенно вступить нечем. `#!users=<ленд реестра>` запоминает реестр.

## Ссылки открываются в установленном приложении

В манифесте заданы `scope: ./` и `handle_links: preferred`, поэтому установленное приложение забирает себе все ссылки внутри `https://b-on-g.github.io/gram/`.

- Android: при установке Chrome лепит WebAPK с интент-фильтрами на scope, и присланный инвайт открывается сразу в Gram. Если система не подтвердила связь сама, помогает переключатель в настройках приложения: «Открывать поддерживаемые ссылки».
- Desktop Chrome начиная со 139 перехватывает ссылки в установленное приложение сам. `launch_handler: navigate-existing` переиспользует уже открытое окно вместо второго, а состояние всё равно живёт в хеше, так что `hashchange` доводит приложение до нужного экрана.
- iOS ссылки в веб-приложение не отдаёт, там остаётся запуск с домашнего экрана.

Иконки в манифесте тут не украшение: без них Chrome не считает приложение устанавливаемым, WebAPK не создаётся и перехватывать ссылки некому. Лежат в `logo/`, попадают в сборку строкой `deploy` в `gram.meta.tree`.

Приложение строит ссылки из `location.pathname`, так что слэш на конце есть всегда. Если ссылку набирают руками, слэш лучше не терять: `/gram` без слэша сначала уходит в редирект, а редирект перехват может не пережить.

Своего домена у приложения нет, `/.well-known/assetlinks.json` лежал бы в корне `b-on-g.github.io` и из этого репозитория туда не дотянуться. WebAPK этот файл и не требует, он нужен нативным приложениям и TWA.

## Запуск локально

```sh
npm create view-tree-lsp@latest gram
npx mam bog/gram
# http://localhost:9080/bog/gram/-/index.html
```

Локальный мастер: `node giper/baza/app/run/-/node.js port=9090`, затем `#!baza=http%3A%2F%2Flocalhost%3A9090%2F`.
