# $bog_gram_follow

Переход по ссылке Gram изнутри приложения, например по отсканированному QR.

- `params( uri )`: из адреса берутся только свои параметры — `invite`, `key`, `join`, `by`, `users`. Всё остальное отбрасывается: QR может подсунуть кто угодно, и, например, `giper_baza_yard_masters` из чужого кода увёл бы приложение на чужой мастер. Без `invite`, `join` или `users` ссылка ничего не открывает.
- `go( uri )`: параметры кладутся в адрес текущего окна, остальные параметры окна сохраняются. Дальше срабатывают обычные обработчики ссылок: личное приглашение заводит диалог, ссылка в группу — заявку, ссылка на реестр запоминает его.
