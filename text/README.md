# $bog_gram_text

Тексты логики Gram, которой некуда положить своё дерево: превью диалога, статусы заявок и приглашений, ошибки, подписи уведомлений, склонения. Дерево на `$mol_object`, строки на английском с `@`, переводы рядом в `text.locale=ru.json` и `text.locale=zh.json`.

Логика берёт тексты через `Text()`, как `Account()` или `People()`:

```ts
@ $mol_mem
Text() {
	return this.$.$bog_gram_text.make({ $: this.$ })
}
```

Функции для текстов любого модуля, и логики, и видов:

- `$bog_gram_text_fill( pattern, vars )` подставляет `{имя}` из `vars`, неизвестные места оставляет как есть.
- `$bog_gram_text_plural( count, forms )` (функция контекста) берёт формы одной строкой через `|` в порядке `one|few|many|other` и выбирает по `Intl.PluralRules` языка интерфейса; недостающие формы берутся из последней. Английский `{n} dialog|{n} dialogs`, русский `{n} диалог|{n} диалога|{n} диалогов`, китайский одна форма `{n} 个对话`.

В тестах грама загрузка словаря заглушена (`text.test.ts`), `@`-тексты отдают свой ключ. Так прогон не зависит от каталога запуска: сборщик зовёт тесты из корня MAM, а словарь лежит в `-/`. Утверждения сравнивают со свойствами `Text()` или подменяют `$bog_gram_text` в контексте.
