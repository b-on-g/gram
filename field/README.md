# $bog_gram_field

Поле с карандашом: заполненное выглядит обычной строкой текста, пока в него не ткнули, а карандаш подсказывает, что строку можно править. Карандаш лежит поверх правого края, поэтому поле остаётся цельным элементом. Используется для своего имени в настройках и для подписи собеседника в шапке чата.
