# $bog_gram_mic

Открытие микрофона с запасными вариантами. На Windows `getUserMedia` может упасть с `NotReadableError: Could not start audio source` при выданном доступе: вход занят другой программой, закрыт в настройках приватности или драйвер не принимает режим обработки.

- `open( devices, wanted )`: запрошенный вход, потом он же без обработки звука, потом остальные входы по очереди. Отказ в доступе не переспрашивается.
- `open_both( devices, audio, video )`: звук и видео одним запросом, а если не вышло, то по отдельности. Что не открылось, того в потоке нет, причины лежат в `errors`.
