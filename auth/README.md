# $bog_gram_auth

Ключ аккаунта Гипер Базы в своём месте локального хранилища (`bog_gram_auth`). Общий ключ Базы один на весь домен, и смена аккаунта здесь меняла бы аккаунт в соседних приложениях того же origin.

- Первый запуск после переезда копирует общий ключ (`$giper_baza_auth`) себе: сохраняются текущий идентификатор и все диалоги. Общее значение остаётся на месте и дальше только читается, им живут соседние приложения.
- Строка из хранилища принимается только целым ключом в 128 байт (публичная часть плюс приватная). Обрезок бросил бы исключение на старте, и приложение осталось бы без экрана: вместо этого заводится новый ключ с предупреждением в лог.
- Класс подменяет `$giper_baza_auth` для всей Базы.
