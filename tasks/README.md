# $bog_gram_tasks

Панель задач открытого чата. Задача — обычное сообщение с отметкой `Task`, список выводится из переписки на лету. Сверху открытые по порядку, под ними сделанные, последние первыми.

- Сообщение или подпись к вложению, начатые с `--` и пробела, уходят задачей без префикса. `—` тоже годится: телефоны сами меняют на него два минуса. При правке префикс не толкуется.
- Отправленное сообщение делает задачей и обратно кнопка в его меню, своё оно или чужое.
- Закрыть и открыть заново может любой участник: `Task_done` — момент закрытия, ноль у открытой.
- При пересылке задача остаётся задачей, но открытой.
