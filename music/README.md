# $bog_gram_music

Страница музыки внутри Gram. Не iframe на `https://b-on-g.github.io/music/`, а
наследник `$bog_music_app` из соседнего репозитория `bog/music`: один бандл — один
аккаунт, одно локальное хранилище, одна тема.

Что переопределено и почему:

- **`title`** — «Музыка», как остальные страницы книги.
- **`Skin`** и **`Theme`** — выключены (`null!`). Палитру и режим темы задаёт
  Gram; второй `$bog_theme_auto` на той же странице спорил бы с корневым за
  одну и ту же ячейку хранилища.
- **`lights()`** — считается по общей теме, чтобы палитра музыки шла в ногу с
  грамом, включая режим «как в системе».
- **`Account()`** — вместо кнопки сброса аккаунта подставляется текст: аккаунт
  общий с Gram, сброс стёр бы переписку, а скачанные треки тоже были бы удалены.
  Своего сброса у музыки больше нет.
- **`tools`** — к грамовским кнопкам страницы добавлено «Свернуть»; штатные
  `Sync_status`, `Version` и переключатель темы убраны, чтобы не дублировать
  шапку Gram.

Страница остаётся в книге после закрытия (`$bog_gram.music_pinned`): вьюха,
убранная из документа, уносит с собой плеер. Скрытие — атрибут
`bog_gram_music_hidden`, а не удаление из `sub`.

Открывается ссылкой `#!music` — так же, как настройки (`$mol_state_arg`).

Побочные эффекты `bog/music` (`$bog_music_boot.init()`, топ-левел код
`app.view.ts` с мастерами на localhost) выполняются при старте Gram: музыка
теперь часть его бандла, и это принято как есть.
