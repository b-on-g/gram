# $bog_gram_album

Кадры сообщения в пузыре, раскладкой как в TG. Один кадр — как раньше, по своим пропорциям; два — рядом; три — большой слева и два справа; четыре — сеткой 2×2; дальше рядами по два и три, чтобы короткие ряды шли сверху.

- `shots`: id кадров, `uri*` и `ratio*` (ширина к высоте) по id. Открытие кадра — `open*`.
- Раскладка (`layout`) считается из одних пропорций, без картинок: место под альбом занято сразу, пока ленды кадров едут, на их месте подложка того же размера.
- Высоту ряда задаёт `aspect-ratio` ряда, сумма пропорций кадров в нём; кадры делят ширину по своей пропорции. Пропорции зажаты в 1:2–2:1, иначе панорама сплющила бы соседа в полоску. Кадр без размеров квадратный.
- Кадр обрезается под ячейку (`object-fit: cover`), целиком он виден в галерее.
- Ширина альбома — `width`; у одного кадра её считает чат по размерам, у нескольких — полный предел.
