# $bog_gram_album

Кадры сообщения в пузыре, раскладкой как в TG. Один кадр — по своим пропорциям, без обрезки и увеличения. Несколько — рядами во всю ширину: разбиение (`chunks`) выбирается из всех возможных так, чтобы пропорции рядов были ближе к 2.5:1, при равенстве короткие ряды сверху. Три кадра с вертикальным первым — он слева, два справа столбцом.

- `shots`: id кадров, `uri*` и `ratio*` (ширина к высоте) по id. Открытие кадра — `open*`.
- Раскладка (`layout`) считается из одних пропорций, без картинок: место под альбом занято сразу, пока ленды кадров едут, на их месте подложка того же размера.
- Высоту ряда задаёт `aspect-ratio` ряда, сумма пропорций кадров в нём; кадры делят ширину по своей пропорции. Пропорции зажаты в 1:2–2:1, иначе панорама сплющила бы соседа в полоску. Кадр без размеров квадратный.
- Кадр обрезается под ячейку (`object-fit: cover`), целиком он виден в галерее. Одиночный (`single`) не обрезается: `scale-down` в `album.view.css`, сильнее правила `$bog_gram_photo`.
- Ширина альбома — `width`; у одного кадра её считает чат по размерам, у нескольких — вся ширина пузыря. За шириной ленты всё следует на CSS, без замеров.
