# $bog_gram_key

Публичный ключ участника в реестре. Ленды диалога шифрованные, и право читать их заворачивается на ключ конкретного человека: по одному идентификатору выдать это право нечем. Лорд это хеш ключа, поэтому чужой ключ, подложенный под чужую запись, отличается от настоящего пересчётом на месте, без сети.
