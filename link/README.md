# $bog_gram_link_synced

Ссылка на пешку в чужом ленде, которая на чтении сама поднимает синк этого ленда. Базовый `remote()` только строит прокси, и без обёртки содержимое отдельного ленда никогда не докачивается: ссылка есть, а данных по ней нет.

- Синк дёргается только на чтении: сразу после записи ленд ещё наш собственный, тянуть нечего.
- Ленд тянется в фоне, обещание ловится и гасится: ждать его нечем, чтение реактивно и повторится само, когда данные приедут.
