# $bog_gram_pick

Страница выбора чата: куда переслать сообщение или с кем поделиться контактом. Сверху «Избранное», ниже видимые чаты в том же порядке, что в меню. Строка отдаёт id чата в `pick*`, ошибку отправки показывает `error` над списком, и страница остаётся открытой, чтобы выбрать другой чат или повторить.
