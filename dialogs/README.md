# $bog_gram_dialogs

Приватный шифрованный список диалогов владельца и всё, что знает о переписке только он.

- `Dialogs`: ссылки на ленды диалогов.
- `Outbox`: неотправленные приглашения вида `лорд|диалог`. Уходят, когда доедут права на чужое лобби.
- `Asks`: очередь заявок в группы, `группа|создатель`. Отдельно от `Outbox`: тот ждёт первого сообщения в диалоге, а заявку шлют до всякого доступа к переписке, и общая проверка её заперла бы.
- `Asked`: заявки, уже доехавшие до чужого лобби. Второй раз их не шлют: отклонённую заявку админ из лобби убирает, и повтор возвращал бы её туда снова. Запись держится тут, пока не выдадут права, по ней же рисуется «ждём, пока примут».
- `Denied`: группы, по заявкам в которые пришёл отказ. Запись из лобби снимается сразу, а сказать о решении надо, иначе заявка исчезнет с экрана без объяснений. Повторный переход по ссылке отметку снимает: отказ не бан.
- `Hidden`: убранные из своего списка диалоги. Без них повторное приглашение вернуло бы диалог обратно.
- `Accepted`: люди, с которыми владелец согласился переписываться. Их диалоги идут в общий список, а не в запросы. Ключ это лорд человека, а не ссылка на диалог: согласие даётся один раз на все его будущие диалоги.
- `Registries`: известные владельцу реестры пользователей.
- `Saved_land`: ленд избранного, заметок для себя. Ссылка личная, поэтому лежит тут, а не в открытом профиле.
- `Saved_lands`: все заведённые ленды заметок. В `Saved_land` побеждает запись, легшая позже. Два устройства, заведя каждое своё избранное, проигравшую ссылку потеряли бы вместе с заметками. Список же сливается, а не перетирается: читаем изо всех лендов, пишем в тот, на который указывает ссылка.
- `Archived`: спрятанные из основного списка диалоги. В отличие от `Hidden`, возвращаются одним кликом.
- `Notes`: подписи собеседников «как я его назвал», ключ это лорд собеседника. Ленд приватный, подпись видна только владельцу.
- `Passes`: ключи собеседников, добытые не из сети, а из ссылки-приглашения.
- `Lobbies`: прежние лобби владельца. Записи, доставленные туда до смены лобби, читаются дальше.
