# $bog_gram_rich

Разметка сообщения в пузыре. Рисует те же теги, что и поле ввода: заголовок (`section`), списки, цитаты, код, выделение. Пробелы между выделениями сохраняются.

Шире пузыря разметка не бывает: длинные слова и код переносятся, а с четвёртого уровня вложенности списки, цитаты и код больше не отступают.

Разметка чужая, поэтому перед вставкой чистится `$bog_gram_write_clean`, а ссылки остаются только `http`, `https`, `mailto` и `tel`.
