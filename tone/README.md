# $bog_gram_tone

Цвета, которых нет в теме.

- `veil`: нейтральная полупрозрачная заливка, чуть темнее на светлой теме и чуть светлее на тёмной. Подложки кода, кружков и плашек.
- `alert`: красный для опасных мест: взведённая корзина, предупреждение про ключ, ошибки.

Модуль без зависимостей, поэтому сборщик ставит его перед потребителями, и константы доступны в `$mol_style_define` на загрузке модуля.
