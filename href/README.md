# $bog_gram_href

Адрес `blob:` для вложения, который сам отзывается.

- `URL.createObjectURL` держит Blob в памяти, пока адрес не отозван, а мем адреса пересчитывается на каждое изменение ленда файла: пока вложение докачивается, кусок за куском. Раньше каждый пересчёт склеивал весь файл в новый буфер и новый Blob, а прежний адрес не отзывался, и кружок на 18 секунд (сотня с лишним кусков по 32 КБ) копил в памяти сотни мегабайт. Айфон выгружал вкладку, и приложение перезагружалось прямо при отправке.
- Объект живёт в меме и принадлежит ему: новый пересчёт уничтожает прежний объект, деструктор отзывает адрес. Адрес создаётся лениво, при первом `url()`.
