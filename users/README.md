# $bog_gram_users

Публичный реестр пользователей: по нему находят собеседников.

- `Title`: название реестра, задаёт создатель, видят все.
- `Lords`: участники.
- `Keys`: публичные ключи участников, ключ словаря это лорд. Со скачанным реестром диалог заводится без сети: одного идентификатора для шифрованного ленда мало, нужен сам ключ, см. `$bog_gram_key`.
