# $bog_gram_react

Реакции на сообщение. Лежат в самом сообщении (`Reactions`): ключ — лорд, значение — эмодзи. У человека одна реакция, новая заменяет прежнюю, пустая строка снимает. Одновременные реакции разных людей мержатся без конфликтов.

Показываются только эмодзи из `kinds` и в его порядке: чужой клиент не подсунет вместо реакции произвольный текст, а плашки не прыгают.
