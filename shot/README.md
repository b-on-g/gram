# $bog_gram_shot

Кадр альбома в сообщении (`$bog_gram_message.Shots`). Лежит в ленде сессии рядом с сообщением, а сама картинка — в своём закрытом ленде.

- `Image`: ссылка на ленд с картинкой. Переписка синкается налегке, тяжёлый кадр приезжает отдельно.
- `Width`, `Height`: размеры кадра в пикселях. Раскладка альбома строится по ним до приезда картинки, и приехавший кадр ничего не сдвигает. Нет размеров — кадр квадратный.
