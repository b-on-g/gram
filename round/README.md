# $bog_gram_round

Кружок в пузыре: круглое видео, длина и кольцо прогресса по краю.

- Играет ровно то, что решил список (`playing`, `toggle`), как голосовое: кружок и голосовое делят одно место «звучит сейчас», и два сразу не заговорят.
- Пока видео не приехало, элемент не заводится: пустой адрес источника браузер честно пытается загрузить.
- Молчит — показывает первый кадр, общую длину и кнопку; играет — со звуком, сколько прошло и кольцо. Кольцо рисует `conic-gradient` по доле из `--bog_gram_round_share`, маской оставлен только обод.
- Размер кадра не хранится: запись квадратная, а показ всё равно круг с `object-fit: cover`.
