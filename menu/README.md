# $bog_gram_menu

Первая страница буклета: список диалогов, кнопки в шапке, плашки ожидания.

- Избранное стоит первой строкой всегда. Вход в архив стоит сверху, вход в запросы снизу, и только пока им есть что показать. Развёрнутый раздел досыпает строки туда же: отдельная страница ради пары спрятанных диалогов или незнакомцев это лишний шаг навигации. Архив раскрывается прямо в списке, чтобы читаться его продолжением, а не врезкой.
- Корзина срабатывает со второго нажатия: первое красит её, второе удаляет, без модалок и системных окон. Красной ждёт максимум одна строка: любой другой клик по списку снимает взвод, чтобы забытая корзина не сработала потом.
- Архив подтверждения не спрашивает: операция обратима. Стрелка на кнопке смотрит туда, куда уедет диалог.
- Непрочитанное в архиве не теряется: на входе в архив стоит сумма счётчиков спрятанных диалогов. Ленд любого из них может быть ещё в пути, такой не считается.
- В строке запроса на месте архива и корзины стоят согласие и отказ: прятать на вторую полку то, о чём решение не принято, незачем. Сама строка остаётся обычной строкой диалога, по клику открывает переписку, и прочитать её до решения нормально. Согласие даётся человеку, а не диалогу: следующий его диалог придёт уже в общий список. Отказ это удаление из своего списка.
- Плашки над списком: ожидание ключа по ссылке-приглашению и судьба заявок в группы. Без них переход по ссылке выглядел бы так, будто ничего не произошло.
