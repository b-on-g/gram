# $bog_gram_lord

Как показывать человека по его лорду.

- `short( lord )`: безымянного собеседника показываем началом и концом идентификатора. По одному только началу у разных людей первые символы совпадают глазом.
- `label( lord, note, name )`: порядок один на всё приложение. Моя подпись важнее имени из чужого профиля, а безымянного и неподписанного показываем сокращённым идентификатором. Аватар при этом остаётся привязан к лорду: от переименования человек лица не меняет.
- `tint( lord )`: номер цвета из палитры, один и тот же лорд всегда красится одинаково.
- `check( lord )`: лордом считаем только полный идентификатор владельца. Ссылку могли обрезать при пересылке, а ссылка на чей-то ленд личным диалогом не открывается, и ждать по ней нечего.
