# $bog_gram_photo

Коробка кадра в пузыре. Размер (`box_width`, `box_ratio`) задаётся из данных сообщения, ещё до самой картинки: лента разложена заранее и от появления кадра не дёргается. Пока картинка не приехала, коробка стоит пустой заливкой, а не значком битой картинки: с пустым адресом картинку не рисуем вовсе.

`object-fit` нет в словаре типизированных стилей, поэтому он в `photo.view.css`. Коробка уже нарезана по пропорциям кадра, и `cover` только подчищает округление до пикселя.
