# $bog_gram_join

Моя заявка в чужую группу, ключ — ссылка на группу (`$bog_gram_dialogs.Joining`).

- `Owner`: лорд создателя группы. Заявку несут в его лобби, а прочитать его из ленда группы просящему нечем: прав ещё не выдали.
- `State`: `queued` — ждёт доставки в лобби создателя, `sent` — доставлена, ждём решения. Принятая заявка из словаря уходит, группа становится обычным диалогом. Отказ здесь не хранится: он лежит в моём лобби и выводится оттуда.

Одна запись на группу: повторная заявка перезаписывает её, а не добавляет новую.
