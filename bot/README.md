# Бот задач

Процесс на маке: берёт задачи из одной группы Грама, решает их через Claude Code и отвечает в чат. В бандл не входит, запускается поверх собранного `bog/gram/-/node.js`. С `push` бот сам выкладывает решение в `master`, ждёт сборку на GitHub и новую версию на сайте, потом закрывает задачу. Без `push` результат — коммит в локальной ветке `bot/N`.

## Подключение

1. `claude` установлен и вошёл в подписку. Если вход в фоне не подхватится: `claude setup-token` и `CLAUDE_CODE_OAUTH_TOKEN` в окружении бота.
2. `~/.gram-bot/config.json`:

```json
{
	"group": "https://b-on-g.github.io/gram/#!join=…/by=…",
	"lords": [ "лорд того, чьи задачи брать" ]
}
```

3. `node bog/gram/bot/bot.js` — бот сам шлёт заявку по ссылке. Админ группы принимает её в экране участников.

Ещё поля: `members` (брать задачи от всех, кому админы дали право писать в группу, а не только от `lords`), `name`, `daily` (запусков в день, 10), `fixes` (попыток починить, 2), `minutes` (на запуск Клода, 30), `masters` (свои мастера), `push` (пушить в `master`), `site` (адрес сайта), `dry` (только прочитать и ответить, без Клода).

`~/.gram-bot` держит ключ бота, хранилище Базы и состояние. Потеря каталога — новый бот, добавлять в группу заново.

## Работа

- Берутся задачи новее первого запуска, у которых текст, фото, отметка `Task`, ответ и время подписаны ключами из `lords` или, при `members`, участников группы. Свои сообщения бот задачами не считает. `Author` не проверяется: его может написать кто угодно.
- Ответ на саму задачу, на сообщение бота или на прежний ответ по ней продолжает ту же задачу в той же сессии Клода. Вопрос или «спасибо» файлов не меняют. Ответ «откати» убирает последнюю выкладку задачи обратным коммитом; номер версии при этом растёт.
- Правки лежат в ветке `bot/N` после каждого хода, поэтому другая задача их не стирает. Продолжение накладывает их на свежий `master`.
- Выкладка: перенос на свежий `master`, проверка, номер версии, обычный пуш без `--force`. Если `master` ушёл вперёд, проверка идёт заново.
- Упала сборка на GitHub — бот убирает правку из `master`, хвост лога уйдёт Клоду с ответом в чате.
- Отчёты: «Взял», «Запушил… на сайте ещё нет», «На сайте», «Сделано, но не выложено», «Не вышло», «Уточни». Итог проверок бот пишет сам, слова Клода идут ниже.

## Автозапуск

Бот живёт под `launchd` (`~/Library/LaunchAgents/gram.bot.plist`, `KeepAlive`). Проснувшись после сна мака, он выходит, как только освободится, и поднимается со свежим соединением. Остановить насовсем: `launchctl bootout gui/$(id -u)/gram.bot`, запустить: `launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/gram.bot.plist`. Перезапустить: `launchctl kickstart -k gui/$(id -u)/gram.bot`.

## Границы

- Клод: `--restricted`, без команд и сети, файлы только в `~/.gram-bot/work`. Это копия дерева без `.git` Грама.
- Сборка и тесты идут в другой копии, `check`, под `sandbox-exec`: без сети, без чтения домашнего каталога. `git` и `npm` там заглушки, иначе сборщик лезет в сеть.
- Ответы и заголовки коммитов чистятся от почты, путей, имени пользователя, адресов и токенов (`scrub`): почту владельца Клод видит в своём контексте. Правка с такими данными отклоняется. Из копий дерева удаляются `.git`, `.baza`, `.env`, ключи.
- Ключ, состояние и настройки лежат в `~/.gram-bot`, в репозиторий не попадают.
- Коммитит бот через голый репозиторий с выключенными хуками. Правки `.git*`, `push/`, `bot/`, `version/`, `*.meta.tree`, `package.json`, ссылки и исполняемые файлы отклоняются.
- Ленд без подписчика сметается, поэтому каждый закреплён солид-атомом. «Задач нет» считается правдой только после прочтения чата.
