# $bog_gram_rights

Права участников группы на готовом `$giper_baza_land_rights`. Источник правды один: ранги в ленде группы. Кто здесь `rule`, тот и админ.

- `land`: ленд группы, по нему строятся строки и решается, можно ли править.
- `lands`: бакеты группы. Сменённый уровень и скорость копируются в каждый бакет, где у человека уже есть ключ. Где ключа нет, там его и не появится: иначе «только новые» тихо открывал бы прошлую переписку.
- `lords`: нынешний состав. Исключённые остаются в ленде с ключом, но в списке их нет.
- `label*`: имя человека вместо ключа.

Поля добавления по ключу нет: человек приходит в группу через `$bog_gram_crew.join`, с выбором истории. Уровня «запрет» тоже нет: исключение заводит свежий бакет, это кнопка в списке участников.
