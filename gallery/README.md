# $bog_gram_gallery

Развёрнутые кадры переписки с листанием, как в Телеграме. Лежит поверх страницы чата, а не всего экрана: на широком мониторе список диалогов остаётся видимым.

```tree
<= Gallery $bog_gram_gallery
	ids <= shot_ids /string
	current? <=> zoom_id?
	uri* <= message_shot_uri*
	close? <=> zoom_close?
```

- `ids`: id кадров в порядке ленты. Галерея не знает, что это сообщения: для альбома это могут быть id отдельных кадров.
- `current?`: какой кадр открыт. Хранит хозяин, поэтому кадр, пришедший в переписку при открытой галерее, просто дописывается в `ids`, а текущий остаётся на месте: он задан id, а не номером. Счётчик сверху («3 из 12») подрастает сам.
- `uri*`: ссылка на картинку. Читается только у текущего и соседа с каждой стороны, они же стоят в документе: соседи подгружаются заранее, а ленды остальных кадров переписки не трогаются.
- `close?`: закрыть.

## Листание

- Палец: кадр едет за ним по горизонтали, отпущенный перелистывается, если ушёл на четверть ширины или двигался быстрее 0.3 px/мс, иначе возвращается. На краю списка кадр тянется втрое туже и не листается.
- Палец вниз: кадр уезжает за ним, фон бледнеет, отпущенный закрывает галерею на пятой части высоты или той же скорости. Вверх жест отпускается.
- Направление решают первые 8 px. Перелистывание анимирует сама смена атрибута смещения у кадра: кадр, ставший текущим, едет из того места, где его отпустили.
- ПК: стрелки клавиатуры, кнопки по бокам при наведении, горизонтальный жест тачпада (`wheel` с `deltaX`, один шаг на жест, конец жеста — пауза 200 мс). Мышью кадр не тянется.
- Закрывают Esc, крестик, тап мимо кадра и свайп вниз. Тап по самому кадру ничего не делает, после тяги клик гасится.
- При открытии галерея забирает фокус, иначе стрелки и Esc уходили бы в поле ввода.

Соседние кадры сдвинуты на ширину слоя единицами контейнера (`cqw`): галерея лежит в странице, а не во весь экран, и `vw` развёл бы их не на ту ширину.
