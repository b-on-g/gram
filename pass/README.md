# $bog_gram_pass

Разбор и проверка публичного ключа участника.

## `parse( str )`

Одной и той же строке отвечает один и тот же объект ключа. Выдача права на шифрованный ленд считает общий секрет и держит его при самом объекте ключа, а фибра перезапускается с начала на каждом ожидании. Свежий разбор на каждой попытке заводил бы счёт заново, и попытки не кончились бы никогда.

## `verified( lord, str )`

Разбор ключа из недоверенного источника. Так приезжают ключи из реестра, из заявки в группу и из ссылки-приглашения. Реестр и лобби открыты на запись всем, ссылку по дороге тоже могли подменить, и тогда диалог, заведённый для одного человека, открылся бы другому.

Лорд это хеш ключа, поэтому подмена ловится пересчётом: не сошлось, значит ключа нет вовсе. Мусор вместо ключа сюда тоже долетает. Разбор бросает исключение, а наружу уходит `null`, и заводить диалог оно не мешает.
