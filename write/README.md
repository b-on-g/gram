# $bog_gram_write

Поле ввода сообщения: `$giper_baza_rich_edit` с двумя режимами. Наружу отдаёт HTML (`html`), текст из него получают `$bog_gram_write_text`.

- **Поле не трогает Базу вообще.** От редактора взяты разметка, панель, хоткеи и команды форматирования, а хранение — нет: вместо pawn ленда поле держит живые DOM-узлы (`nodes`). `pawn()` бросает, `selection_save`/`selection_load` пустые. Первая версия держала текст в `$giper_baza_land.make()`, а ленд без явной ссылки получает ссылку домашнего ленда своего лорда: каждая буква через `post` писала разметку в корень home-ленда, затирала указатели профиля (`Dialogs_land` и прочие) и сохраняла это в IndexedDB — аккаунт висел на «Загружаем данные аккаунта…». Свой ленд-область тоже не годится: `post` всё равно зовёт `broadcast` в `yard`, а уничтожение ленда — `forget_land`. Тест подменяет `$giper_baza_land`, `$giper_baza_glob` и `$giper_baza_auth` бросающими и проверяет, что набор, правка и очистка их не зовут.
- Узлы не пересоздаются, пока поле само отдаёт свой `html` (`html_last`): браузер сам держит каретку и выделение, в том числе назад и на телефоне. Новые узлы строятся, только когда `html` пришёл снаружи — черновик другого диалога, правка, очистка после отправки.
- Наружу HTML уходит вычищенным (`$bog_gram_write_clean`): без атрибутов, кроме `href` у ссылки, и без тегов вне белого списка — картинка из вставленной страницы не станет пикселем-шпионом в сообщении. Разбор везде как HTML (`text/html`): XHTML-разбор редактора падал на `&nbsp;`.
- Форматированная вставка своя (`paste_rich`): HTML из буфера чистится тем же белым списком до того, как попасть в документ, иначе `<img onerror>` из буфера сработал бы уже при вставке.
- `rich` выключен — простой режим: нет панели, вставка только текстом, хоткеи форматирования (Alt+S, Tab в список и прочие) ничего не делают, Tab уводит фокус. Включён — панель редактора, скрепка редактора спрятана: файлы шлёт чат.
- `length_max` держится на вводе: `beforeinput` отменяет вставку, не влезающую в остаток, вставка из буфера обрезается по остатку. Длина считается по тексту, тем же `$bog_gram_write_text`, что и у чата.
- Вставка с файлами не трогается: её ловит чат и кладёт в очередь вложений.
- Enter отправляет только там, где есть физическая клавиатура: без тача, с `any-pointer: fine` или с `hover: hover`. На телефоне Enter переносит строку, отправка кнопкой. Shift+Enter переносит строку сам, Ctrl/Cmd+Enter — через `insertLineBreak`. Enter, подтверждающий набор IME, не отправляет.
- `any-pointer`, а не `pointer`: на ноутбуке с тачскрином основным указателем считается последний использованный, и после перезагрузки это тач.
- Подсказка (`Hint`) — отдельный вид поверх пустого поля, сквозь неё проходят тапы. Пустое поле редактор рисует заготовкой `<section><p>`, у которой первый абзац — заголовок; в простом режиме он сброшен до обычного текста.
