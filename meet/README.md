# $bog_gram_meet

Встреча — постоянная ссылка на звонок группы, как в Телемосте. Чат встречи — сама группа Gram, звонок — обычная комната `$bog_gram_call` из этой группы.

## Ленды

- Прихожая (`hall`, `$bog_gram_meet_hall`) — открытый ленд, пишут все. Ссылка: `#!meet=<прихожая>/by=<лорд создателя>`. Шифровать её нельзя: стучащемуся ещё не выдано ничего, а ленд, куда пишут все, в Базе всегда открыт.
  - `Group`, `Title`, `Confirm`, `Room` пишет создатель группы. Читаются они только из его юнитов (`vary_of( owner )`, юниты в Базе лежат по полному лорду автора), чужая запись в эти поля ничего не значит. Создатель едет в ссылке, а не берётся из ленда: `land_grab` заводит ленду своего короля с новым ключом, это не создатель группы.
  - `Knocks` — стуки, запись `группа|лорд|ключ` в формате заявок `$bog_gram_lobby`. Стук засчитывается, только если автор юнита и есть лорд из записи: постучаться от чужого имени нельзя.
- Группа хранит ссылку на прихожую в `Meet` (`$bog_gram_dialog`). Прочитать её могут только участники.

Что видно в прихожей любому, у кого есть ссылка: название встречи, id группы, ключи постучавшихся, ссылка на комнату звонка. Переписка и состав закрыты.

## Звонок открыт любому со ссылкой

Как в Телемосте: перешёл по ссылке или QR-коду и сразу в звонке, без заявки и подтверждения. Комната звонка встречи заводится открытой (`$bog_gram_call_room.grab( null )`): ленд не шифруется и открыт всем на запись. Поэтому:

- любой, у кого есть ссылка встречи, видит комнату и может зайти в звонок; в сигналинге (адреса и кандидаты WebRTC) виден IP участников друг другу и всем, кто читает ленд комнаты;
- чат группы по-прежнему закрыт до выдачи ключа, звонок его не открывает.

Ссылка на комнату лежит в `Room` прихожей, а не едет в самой ссылке встречи: ссылка осталась бы короткой для QR, а комнату можно сменить, не раздавая новую ссылку. Читается она только из юнитов создателя (`room_of`), как `Group`. Встреча одна, комната одна: `call( id )` берёт уже опубликованную, а если её нет (встреча заведена до этого изменения, с закрытой комнатой), создатель заводит новую открытую и записывает в `Room` (`room_make`). То же делает `auto()` на клиенте создателя, не дожидаясь звонка, поэтому старая встреча начинает пускать сразу в звонок, как только создатель откроет Gram. Пустым `Room` считается только прочитанное поле, а не ещё грузящаяся прихожая (`room_stored`), иначе комната заводилась бы заново на каждом старте. Остальные участники при старте звонка используют `Room`, если она есть.

## Сценарии

- `make( id )`: только создатель группы заводит прихожую и пишет её в `Meet`. Повтор отдаёт уже заведённую.
- `take( link )`: переход по ссылке. Если в прихожей есть `Room`, любой (и участник, и нет) сразу попадает в звонок: `take` отдаёт `plan: 'call'` с комнатой, участнику заодно открывается группа. Для неучастника в фоне уходит только стук, без заявки в лобби: заявка выводила над списком диалогов «заявка ждёт подтверждения», а впускают по стуку и так. Группа откроется, когда доедет ключ, но звонок от этого не прерывается. Встречи без `Room` работают как раньше (`ask`). Участником считает сама База: у меня в ленде группы ранг не ниже `post` и есть ключ к текущей сессии (`Talk().inside`). Список диалогов и приглашения тут не в счёт: приглашение доезжает раньше ключа, и открытый по нему чат весь был `Access denied`. Участнику открывается группа. Без `Room` остальные отправляют обычную заявку создателю (`Lobby().send`) и стучат в прихожую (`knock`). Заявка даёт стучащемуся привычный путь «отправлена → принята», стук — видимость для всех админов: в лобби создателя другим админам не заглянуть.
- `wait` и `entered()`: постучавшийся ждёт, пока до него доедет ключ, и тогда сам входит в группу (`.meet_enter`). Комната последнего звонка открывается следом, когда доедет и ключ к ней (`room_wait`, `room_ready()`).
- `knocks_all( id )`: все честные стуки. `knocks_of( id )`: кроме тех, у кого в ленде группы уже есть ранг участника (`Talk().member_is`). Страница участников показывает их вместе с заявками из лобби, по одной строке на человека.
- Впустить — тот же `Lobby().apply`, то есть `Crew().join`. `join` дополнительно выдаёт новичку право на комнату последнего звонка группы, если впускающий в ней правит. Комнату звонка в группе с этого изменения заводящий открывает админам с правом `rule`, поэтому впустить в идущий звонок может любой админ.
- `forget( entry )`: стук вычёркивается после решения. `auto()` вычёркивает и стуки уже впущенных, но только при `ask`.
- `mode( id )`: `auto` по умолчанию, `ask` при `Confirm = on`. Переключает только создатель. При `auto` клиент любого админа, у которого открыт Gram, впускает постучавшихся сам (`auto()` → `admit`), с историей переписки, а на странице звонка очередь стучащихся не показывается совсем. При `ask` очередь с кнопками остаётся.

## Впуск при auto доводится до конца

`Crew().join` по пути несколько раз ждёт загрузки ленд (бросает промис). Внутри мема `auto()` под `$bog_gram_soft` это тихо возвращало пустоту, а `join` к тому времени уже успевал выдать ранг в ленде группы. На следующем проходе стучащийся считался участником (`member_is`), и `auto()` стирала стук, не доведя `join` до приглашения и ключей: стучащийся оставался без ключа группы, стука нет, а соединение со звонком в таком состоянии не поднималось (замер двумя браузерами: `join throw promise` несколько раз, `join ok` ни разу, у гостя `inside` ложно, в комнате `seats` 1 вместо 2). Раньше стук вычёркивался по рангу, а не по результату впуска. Теперь `admit( entry )` запускает `Lobby().apply` в своей фибре (`$mol_wire_async`, как ручной допуск), повторно не стартует, пока идёт (`admitting`), и стирает стук только когда `apply` вернул лорда. Стук члена группы без ключа при `auto` впускается заново, так лечится и прерванный ранее впуск. При `ask` стук члена группы по-прежнему просто стирается.

## Ограничения

- При `auto` без админа онлайн никто не войдёт: ключ от шифрованной группы выдаёт человек, а не ссылка.
- Два админа онлайн могут впустить одного человека одновременно. Повторный `join` выдаёт те же права ещё раз, вреда нет, но приглашение уйдёт дважды.
- Звонок каждый с каждым, около пяти человек. Предела в комнате пока нет.
