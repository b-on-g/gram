# $bog_gram_members

Страница участников группы. Есть только у группы: в переписке вдвоём перечислять некого.

- Создатель отмечается отдельно от назначенных админов: его права никто не отберёт, он король ленда.
- Назначает админов создатель, и только тех, кто им ещё не стал. Убирает людей админ. Себя убрать нельзя, для этого есть выход из группы, он не трогает остальных.
- «Убрать» срабатывает со второго нажатия, как корзина в списке диалогов: первое красит кнопку, любое другое снимает взвод.
- Что значит «убрать» и «выйти», объясняется строкой на месте, а не в подсказке кнопки: на телефоне подсказку никто не увидит, а обе операции необратимы. Пояснение про «убрать» видит только тот, кто может убирать.
- Звать людей может админ, поэтому у остальных блока добавления нет вовсе, вместе со ссылкой-приглашением и заявками: принять заявку им всё равно нечем. Выбор истории стоит наверху блока и действует на все способы добавить человека: заявку, человека из реестра и набранный руками ID, см. `history` в `$bog_gram_crew`.
- Админ получает полное управление лендом и вместе с правом звать людей может менять чужие права. Об этом страница говорит создателю прямо.
- Выход из группы это удаление диалога из своего списка: ленд остаётся у остальных, снимается своя ссылка и слежка за бакетами. Из участников при этом не вычёркиваемся: это запись в тот же ленд, а писать в группу, из которой уходишь, лишнее.
- Под именем просящего стоит сокращённый лорд моноширинным шрифтом: имя человек задаёт себе сам, и по одному имени не понять, того ли впускаешь.
