# $bog_gram_settings_key

Ключ аккаунта в настройках: показать, скопировать, скачать файлом, войти по чужому ключу.

- Строка ключа это полный доступ к аккаунту, поэтому она никуда не уезжает: только на экран и только по явной просьбе. Пока ключ скрыт, его не читает никто: ни абзац, ни кнопка копирования, ни QR, в дереве компонентов их просто нет.
- Ключ ломается по символам, а не уходит в горизонтальную прокрутку: длинная строка без пробелов иначе распирала бы колонку. Перенос рисуется стилем и в текст не попадает, копируется цельная строка. Высота ограничена, чтобы блок не занял пол-экрана.
- QR на белой подложке: красный на тёмном фоне без неё читается как инверсный код, и не всякий сканер его берёт.
- Ключом считается только строка полного размера, 128 байт: обрезок или случайный текст молча увели бы в пустой аккаунт без диалогов.
- Первый клик по «Войти» взводит кнопку, второй применяет. Заведомый мусор до взвода не доходит, строка проверяется сразу.
- При входе снимается отметка подписки на пуши: она выдана прежнему лорду, и настройки не должны обещать то, чего нет. Весь граф данных завязан на текущий ключ, поэтому страница начинается заново.
- Файл читается асинхронно, поэтому из обработчика уходим в фибру.

Состояние блока (показан ли ключ, взведён ли вход, ошибка) живёт в самом блоке. Закрытая страница настроек уходит из книги и уничтожается вместе с ним, поэтому секрет не остаётся на экране, а забытый взвод не сработает потом.
