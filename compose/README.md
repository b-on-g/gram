# $bog_gram_compose

Страница нового диалога: поле для ID собеседника и люди из моих реестров.

- `open*?`: открыть диалог с человеком. Решение (уже есть такой диалог или надо ждать его ключ) принимает корень, страница только передаёт лорд и очищает поле.
- Один человек одна строка, даже если он числится в нескольких реестрах. Пока реестр один, называть его в каждой строке незачем.
- Без людей список говорит, откуда их взять: вступить в реестр или создать свой.
- Если открыт чужой реестр, а меня в нём нет, сверху стоит плашка «Вступить»: собеседники листают его список и меня там не видят.
