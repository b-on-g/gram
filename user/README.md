# $bog_gram_user

Публичный профиль в home-ленде: ссылки на служебные ленды владельца, см. `$bog_gram_account`. Профиль открыт всем, поэтому в нём нет ничего, что связывает лорд с человеком.

- `Name`: прежнее открытое имя. Новые версии сюда не пишут, а при старте переносят его в приватный список и стирают: имя в открытом профиле превращало анонимный лорд в человека. Читается только как запасной путь для собеседников на старых версиях.
- `Inbox_land`: лобби для приглашений, заявок и отказов.
- `Dialogs_land`, `Devices_land`: приватные зашифрованные ленды владельца.
- `Monitor_land`: прежний открытый монитор. Больше не пишется.
- `Watch_land`: монитор для пуш-демона. Ленд зашифрован, право чтения выдаётся только ключу демона.
